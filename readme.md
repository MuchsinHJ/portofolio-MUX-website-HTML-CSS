## 📌 Deskripsi

Website ini merupakan portofolio personal yang dirancang untuk memperkenalkan diri, menampilkan keahlian teknis, dan menawarkan layanan sebagai seorang Full Stack Developer. Dibangun menggunakan teknologi web dasar — **HTML**, **CSS**, dan **JavaScript** — dengan pendekatan desain yang modern, gelap (*dark theme*), dan elegan.

Website dapat diakses langsung melalui browser tanpa framework tambahan, menjadikannya ringan, cepat, dan mudah di-*deploy* ke mana saja.

## ✨ Fitur Website

- **Hero Section** — Perkenalan singkat dengan animasi masuk yang halus
- **About Me** — Profil lengkap beserta deskripsi pengalaman dan spesialisasi
- **Tech Stack** — Tampilan teknologi yang dikuasai, dikelompokkan per kategori
- **My Services** — Layanan yang ditawarkan dengan desain kartu bertekstur
- **Statistics Bar** — Statistik pengalaman, project, kursus, dan bahasa pemrograman
- **Footer** — Tautan cepat, legal, dan ikon media sosial
- **Sticky Navbar** — Navigasi yang mengikuti scroll dengan efek shadow
- **Hamburger Menu** — Navigasi responsif untuk perangkat mobile dan tablet
- **Responsive Design** — Tampilan optimal di semua ukuran layar

## 📱 Responsive Breakpoints

| Breakpoint | Target | Perubahan Utama |
|---|---|---|
| `≤ 1024px` | Tablet | Layout about jadi kolom, padding navbar mengecil |
| `≤ 768px` | Mobile | Hamburger menu aktif, hero gambar pindah ke atas, services full-width |
| `≤ 480px` | Small Mobile | Font lebih kecil, stats & footer ditumpuk vertikal |

## ⚙️ Cara Menjalankan

Website ini adalah proyek **statis** — tidak memerlukan build tools atau server khusus.

### Lokal (Langsung di Browser)
```bash
# Clone repository
git clone https://github.com/MuchsinHJ/portofolio-MUX-website-HTML-CSS.git

# Masuk ke direktori
cd portfolio

# Buka di browser
open index.html
# atau klik dua kali file index.html
```

### Menggunakan Live Server (Rekomendasi untuk Development)
```bash
# Jika menggunakan VS Code, install ekstensi Live Server
# lalu klik kanan index.html → "Open with Live Server"
```
